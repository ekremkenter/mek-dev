An embeddable solidarity banner any site can add with one script tag. React
mounted inside a Shadow DOM so host-page styles can't clash, config passed
via a data attribute, built with a custom esbuild pipeline, generator UI with
live preview at /palestine.

Technically interesting (third-party embed done right) and personally
meaningful — worth keeping in the portfolio as both.
