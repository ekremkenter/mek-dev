# Outline: "Chat-native UI — designing for conversations, not screens"

Launch post #2. Based on Ekrem's AWS talk. TODO: event name, date, link.

1. **Hook** — we spent 15 years compressing tasks into taps; LLMs just made
   language the interface again.
2. **Chat-native ≠ chatbot** — the 2017 chatbot wave failed on rigid intents;
   what's different now (reasoning, tool use, MCP).
3. **Design principles** — when to answer vs. when to render UI in the
   conversation; progressive disclosure; trust and confirmation patterns for
   actions (payments, bookings).
4. **A worked example** — airline use case, connecting to the MCP post.
5. **Takeaways** — heuristics teams can apply tomorrow.
