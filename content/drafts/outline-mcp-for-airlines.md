# Outline: "Teaching AI assistants to fly — MCP in the airline industry"

Launch post #1 for the new site. Audience: engineers + product leaders
watching MCP adoption. This is the post version of work Ekrem is already
doing publicly at the Digital Lab.

1. **Hook** — a passenger asks Claude "am I going to make my connection?" and
   gets a real answer from airline systems. What had to exist for that moment.
2. **Why airlines are a hard, great fit for MCP** — deep legacy systems, high
   transaction stakes, huge intent variety (booking, baggage, status, upgrades).
3. **What we built** — the MCP platform story, to the depth confidentiality
   allows. TODO: Ekrem defines the line.
4. **Lessons** — tool design for non-deterministic callers; auth for
   agent-initiated actions; what chatbots-era lessons (Boti!) transferred and
   what didn't.
5. **What's next** — chat-native UI as the successor to app screens.
