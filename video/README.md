# mek.dev videos

Remotion compositions built from the site's narrated posts.

```bash
pnpm install
pnpm studio                 # preview in the browser
pnpm render:prize-short     # renders out/prize-short.mp4
```

Audio clips in `public/` are cut from the narrations made by
`scripts/tts/narrate.mjs` (an AI clone of Ekrem's voice). Disclose that when
uploading: tick YouTube's altered or synthetic content box and say so in the
description.
